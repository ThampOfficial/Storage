# แผนที่เก็บของ (Storage)

เว็บแอปจดว่าของแต่ละชิ้นเก็บอยู่ที่ไหน
- มีหลายห้อง แต่ละห้องมีผังเป็นตาราง (A, B, C… × 1, 2, 3…)
- วางชั้นวาง / กล่อง / ตู้ / ลิ้นชักลงในผังได้ และใส่กล่องไว้ในชั้นวางได้ (เช่น R1 › 1A, 2A)
- จดของในแต่ละกล่องพร้อมจำนวนและรูป ค้นหาว่าของอยู่ไหน ย้ายของหรือย้ายกล่องได้

ข้อมูลเก็บใน **Google Sheet** ของคุณเอง ส่วนรูปเก็บในโฟลเดอร์ **แผนที่เก็บของ - รูป** ใน Google Drive

## ตั้งค่าครั้งแรก (ประมาณ 5 นาที)

1. สร้าง Google Sheet ใหม่ ตั้งชื่ออะไรก็ได้ เช่น `แผนที่เก็บของ`
2. ในชีต ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมออก แล้ววางโค้ดจากไฟล์ [`Code.gs`](Code.gs) ทั้งไฟล์
4. แก้บรรทัด `const KEY = 'เปลี่ยนเป็นรหัสของคุณ';` ให้เป็นรหัสลับของคุณเอง แล้วกดบันทึก
5. เลือกฟังก์ชัน **setup** ด้านบน แล้วกด **Run**
   - Google จะขอสิทธิ์ใช้ Sheet และ Drive ให้กดอนุญาต
   - ถ้าขึ้นว่า "Google hasn't verified this app" ให้กด Advanced → Go to … (unsafe) ได้เลย เพราะเป็นสคริปต์ของคุณเอง
   - เสร็จแล้วชีตจะมีแท็บ `rooms`, `units` และ `items`
6. กด **Deploy → New deployment** เลือกประเภท **Web app** แล้วตั้งค่า
   - Execute as: **Me**
   - Who has access: **Anyone**
7. กด Deploy แล้วคัดลอกลิงก์ **Web app** ที่ลงท้ายด้วย `/exec`
8. เปิดแอป กดปุ่ม **ตั้งค่า Google Sheet** แล้ววางลิงก์กับรหัส KEY จากข้อ 4

> ถ้าแก้ `Code.gs` ทีหลัง ต้องไปที่ Deploy → Manage deployments → แก้ไข (รูปดินสอ) → Version: **New version** แล้วกด Deploy ใหม่ ลิงก์จะยังเหมือนเดิม

## ให้เพื่อนช่วยแก้

ในหน้า **ตั้งค่า Google Sheet** ของแอปมีปุ่ม **คัดลอกลิงก์** ส่งลิงก์นี้ให้เพื่อน เพื่อนเปิดแล้วจะเชื่อมกับชีตเดียวกันให้อัตโนมัติ
- เพื่อนไม่ต้องมีสิทธิ์ในชีต
- ในลิงก์มีรหัสอยู่ ส่งให้เฉพาะคนที่ไว้ใจ
- ถ้าอยากตัดสิทธิ์ทุกคน ให้เปลี่ยน `KEY` ใน Code.gs แล้ว deploy ใหม่

ข้อมูลจะดึงใหม่ทุก 30 วินาที และทุกครั้งที่กลับมาเปิดหน้าแอป

## ใช้งาน

- ผังล็อกไว้เป็นค่าเริ่มต้น กด **จัดผัง / ปรับขนาด** ก่อน แล้วค่อยลากย้าย หรือลากขอบเพื่อปรับขนาด
- ปุ่ม − / + ใช้ปรับจำนวน
  - ถ้าเพิ่มของชื่อซ้ำในกล่องเดิม จำนวนจะบวกเพิ่มให้
  - เหลือ 0 จะขึ้นป้าย "หมดแล้ว" และมีปุ่ม **เอาออก**
- ถ้ายังไม่ได้เชื่อม Google Sheet แอปจะแสดงข้อมูลตัวอย่างในโหมดทดลอง และไม่บันทึกอะไร
